# apps/dudus

Part of the `ericgitonga-com` monorepo (migrated from the standalone `dudus-app` repo, now
archived — full history preserved). Photo-based lookup companion for the Dudus/Kito's Dudus
Kenyan entomology curriculum, live at `dudus.ericgitonga.com`.

## Local setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). A health check is available at
`/api/health`.
